# Cистема управления взаимоотношениями с клиентами CRM 

## Описание
Модуль представляет собой систему управления взаимоотношениями с клиентами, интегрированную с AI-инструментами для автоматизации продаж. Система позволяет вести учет клиентов, контактов и сделок, визуализировать воронку продаж через Kanban-доску, планировать активности и анализировать эффективность работы.

## Функциональные возможности

### 1. Управление сделками (Deals)
*   **Жизненный цикл:** Создание, редактирование и хранение истории сделок.
*   **Воронка продаж:** Визуализация сделок на Kanban-доске с возможностью перемещения между стадиями.
*   **Параметры:** Учет суммы, вероятности закрытия, дедлайнов и приоритетов (от низкого до критического).
*   **Валидация переходов:** Проверка обязательных условий при смене стадии (например, наличие прикрепленного файла или привязанного контакта).
*   **Причины проигрыша:** Обязательная фиксация причин при переводе сделки в статус «Проиграна».

### 2. Клиенты и контакты (Clients & Contacts)
*   **База клиентов:** Хранение данных об организациях (ИНН, отрасль, сегмент, годовой оборот, адреса).
*   **Контактные лица:** Учет сотрудников клиента с указанием их роли в принятии решений (ЛПР, ЛВПР, линейный персонал).
*   **Коммуникации:** Хранение предпочтительных каналов связи (Email, Phone, MAX).
*   **Связи:** Возможность привязки нескольких контактов к одной сделке с выделением основного.

### 3. Активности и Timeline
*   **Лента событий:** Хронологический лог всех действий по сделке (комментарии, звонки, встречи, системные логи).
*   **Управление файлами:** Загрузка и хранение документов, привязанных к конкретным активностям или сделкам.
*   **Планирование:** Создание задач и напоминаний с привязкой к дате и времени.
*   **Упоминания:** Система уведомлений через механизм `@username` в комментариях.

### 4. Интеллектуальные функции (AI Processor)
*   **Автоматизация входящих:** Анализ текста входящих сообщений для автоматического создания сделок и извлечения контактных данных.
*   **Прогнозирование:** Оценка вероятности закрытия сделки на основе анализа истории активностей.
*   **Генерация контента:** Создание кратких резюме по сделке (Summary) и подготовка персонализированных Follow-up писем.
*   **NBA (Next Best Action):** Рекомендации по следующим шагам для «зависших» сделок.

### 5. Напоминания и уведомления
*   **Daily Agenda:** Ежедневная утренняя рассылка списка задач для менеджеров.
*   **Мониторинг стагнации:** Автоматическое выявление сделок без активности в течение заданного периода.
*   **Контроль дедлайнов:** Уведомления о приближающихся сроках задач и просроченных событиях.

### 6. Обмен данными (Exchange)
*   **Экспорт:** Выгрузка базы сделок в формат CSV с сохранением структуры (Клиент, Проект, Статус, Ответственный и т.д.).
*   **Импорт:** Загрузка данных из CSV с автоматическим созданием цепочек «Клиент — Контакт — Сделка — Активность».

## Техническая архитектура

*   **Service Layer:** Бизнес-логика вынесена в специализированные сервисы (DealManager, AiProcessor, ReminderManager, Timeline).
*   **Событийная модель:** Использование системы Events для интеграции с внешними модулями (уведомления, аудит).
*   **Аудит:** Логирование изменений ключевых сущностей для отслеживания истории правок.
*   **CLI Tasks:** Фоновые задачи для обработки ежедневных рассылок и проверки дедлайнов по расписанию (Cron).

## Структура данных
*   `deals`: Основная информация о сделках.
*   `clients`: Карточки организаций.
*   `contacts`: Данные контактных лиц.
*   `stages`: Настройки этапов воронки и правил перехода.
*   `activities`: Все типы взаимодействий и задач.
*   `ai_analysis`: Хранилище результатов работы нейросети (инсайты, оценки, резюме).
*   `loss_reasons`: Справочник причин отказа.
