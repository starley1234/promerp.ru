# erp409_costing — объяснимая себестоимость

Модуль считает версионируемый план/факт производственного заказа и не является бухгалтерской книгой.

## Источники

- материалы плана: `erp_402_order_items`; факт: проведённые `erp_401_movements` с `doc_type=erp402_order`;
- ставка материала: последняя рублёвая `erp_403_prices`, для факта — на дату движения;
- труд: `erp_408_operations.norm_cost`, факт пропорционален подтверждённому времени;
- оборудование: `erp_408_work_centers.cost_per_hour × часы`;
- брак — аналитическая доля уже понесённых затрат, `included_in_total=false`, чтобы не удваивать итог.

Каждая строка хранит количество, ставку, формулу, тип/ID первичного факта и человекочитаемую ссылку на источник. Отсутствующая ставка даёт ноль **и предупреждение**, а не молчаливое утверждение о бесплатном ресурсе. Пересчёт всегда создаёт новую неизменяемую по смыслу версию; утверждение фиксирует решение человека.

## UI и права

`/costing` доступен из общего меню, mobile drawer и Ctrl+K. Верхнее меню модуля задаёт `Controller_Erp409_Main`.

- `erp409.view` — просмотр;
- `erp409.calculate` — создать новую черновую версию;
- `erp409.approve` — утвердить версию.

MCP содержит только read-only `costing.orders` и `costing.explain`: AI объясняет расчёт, но не пересчитывает и не утверждает источник истины.

Миграция автоматически доступна через штатную админку `/migrate_pg` после включения модуля в bootstrap.
