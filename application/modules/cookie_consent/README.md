# Kohana 3.3 Cookie Consent Module

Модуль для Kohana 3.3, который реализует всплывающее окно с уведомлением о файлах cookie, соответствующее требованиям законодательства о конфиденциальности данных. Окно появляется при первом посещении сайта и скрывается после того, как пользователь нажимает кнопку закрытия, устанавливая cookie для запоминания выбора.

## Особенности

*   **Простота использования:** Легко интегрируется в существующие проекты Kohana 3.3.
*   **Автоматическое скрытие:** Окно не отображается, если пользователь уже дал согласие (установлен соответствующий cookie).
*   **AJAX-закрытие:** Использует AJAX для установки cookie без перезагрузки страницы.
*   **Кастомизация:** Легко настраивается через CSS и HTML-шаблон.
*   **Гибкое размещение:** HTML всплывающего окна может быть вставлен в любой шаблон.

## Требования

*   Kohana 3.3.x
*   PHP 5.3+

## Установка

1.  **Скопируйте модуль:**
    Разместите папку `cookie_consent` в директории `modules/` вашего проекта Kohana.

    ```
    modules/
    └── cookie_consent/
        ├── init.php
        ├── classes/
        │   └── controller/
        │       └── cookieconsent.php
        ├── views/
        │   └── cookie_consent/
        │       └── popup.php
    ```

2.  **Включите модуль:**
    Откройте файл `APPPATH/bootstrap.php` и добавьте `cookie_consent` в массив `Kohana::modules()`:

    ```php
    Kohana::modules(array(
        // ... другие модули
        'cookie_consent' => MODPATH.'cookie_consent', // Включите ваш модуль
    ));
    ```

3.  **Интегрируйте в шаблон:**
    В вашем основном шаблоне (например, `APPPATH/views/template.php` или `APPPATH/views/layouts/default.php`), перед закрывающим тегом `</body>`, добавьте вызов статического метода для вставки HTML и подключите CSS/JS файлы:

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title><?php echo $title; ?></title>
        <?php
        // Подключаем CSS для модуля
        echo HTML::style('media/cookie_consent/css/cookie_consent.css');
        ?>
        <!-- Ваши другие CSS-файлы -->
    </head>
    <body>

        <!-- Ваш основной контент страницы -->
        <?php echo $content; ?>

        <?php
        // Вставляем HTML всплывающего окна
        echo Controller_CookieConsent::get_popup_html();
        ?>
		
        <!-- Ваши другие JS-файлы -->
    </body>
    </html>
    ```

## Использование

После установки и интеграции, всплывающее окно будет автоматически отображаться для новых посетителей или тех, у кого нет cookie `cookie_consent_closed`.

### Как это работает:

1.  **Первый визит:** При первом посещении страницы, метод `Controller_CookieConsent::get_popup_html()` проверяет наличие cookie `cookie_consent_closed`. Поскольку его нет, он рендерит HTML всплывающего окна.
2.  **Отображение:** JavaScript (`cookie_consent.js`) обнаруживает наличие окна и делает его видимым с небольшой задержкой.
3.  **Согласие:** Когда пользователь нажимает на кнопку закрытия (крестик), JavaScript:
    *   Скрывает окно.
    *   Отправляет AJAX-запрос на маршрут `/cookie_consent/close`.
4.  **Установка Cookie:** Контроллер `Controller_CookieConsent::action_close()` обрабатывает этот запрос, устанавливая cookie `cookie_consent_closed` со сроком действия в 1 год.
5.  **Последующие визиты:** При следующих посещениях, `Controller_CookieConsent::get_popup_html()` обнаруживает наличие cookie `cookie_consent_closed` и возвращает пустую строку, предотвращая отображение окна.

## Кастомизация

Вы можете легко изменить внешний вид и текст всплывающего окна:

*   **Текст и HTML:** Отредактируйте файл `modules/cookie_consent/views/cookie_consent/popup.php`.
*   **Стили:** Измените файл `modules/cookie_consent/media/css/cookie_consent.css`.
*   **Поведение JS:** Отредактируйте `modules/cookie_consent/media/js/cookie_consent.js` (например, изменить задержку появления).

## Тестирование

1.  **Очистите cookie:** Удалите все cookie для вашего домена в браузере.
2.  **Загрузите страницу:** Вы должны увидеть всплывающее окно.
3.  **Закройте окно:** Нажмите на крестик. Окно должно исчезнуть.
4.  **Обновите страницу:** Окно больше не должно появляться.
5.  **Для повторного тестирования:** Снова удалите cookie `cookie_consent_closed` из настроек вашего браузера.
